# 合盖助手 (Clamshell Assistant)

一个 macOS 菜单栏小工具，一键切换合盖运行模式，让 Mac 合上盖子后继续跑 Agent 任务。

本应用内置 [Reminal](https://github.com/harshalgajjar/Reminal) 3.19.4 的**合盖精简版**（源码在 [`ThirdParty/reminal-lid`](ThirdParty/reminal-lid)），只保留合盖相关功能，已去掉全部远程功能，无需再单独安装 Reminal。

## 功能

- **开启合盖运行**：关闭系统睡眠（`pmset -a disablesleep 1`），打开合盖与保持解锁，并在助手运行期间启动本地合盖服务。
- **关闭合盖运行**：把上述三项关闭并停止合盖服务。
- 合盖服务会在合盖相关设置打开时防止空闲睡眠（`caffeinate -i`）和显示器空闲休眠/自动锁屏（`caffeinate -d`）；无物理显示器时按需创建虚拟显示器，合盖时调暗内建屏幕、开盖时恢复。退出助手会释放这些防休眠项；**V2 起，正常退出时也会把本助手自己设置的「系统禁止睡眠」恢复**（你选择的开/关会记住，下次启动按原逻辑恢复）。
- **菜单栏图标**：合盖运行中是 Mac Studio 且状态灯亮起，正常模式是 MacBook。开关成功时播放原来的设备变形、亮灯和扩散光环。读取失败会显示「状态暂不可用」并保留上次图标。
- **只有开或关，没有“部分开启”**：助手记住你最后选的是开还是关。合盖模式、保持解锁、系统禁止睡眠三项里任何一项被别的程序（例如 UU远程的“保持唤醒”、独立 Reminal 命令行）改掉，助手会在刷新、唤醒、启动或检测到设置变化时自动改回，不弹密码框；改不回来就直接报错并指明是哪一项，例如「开启失败：保持解锁未生效」「未完全关闭：系统禁止睡眠仍开着」。被反复改回时 2 分钟内最多自动恢复 3 次，然后停下报错，点「刷新状态」会再试。
- 从旧版升级后、还没按过开关时，助手以 Reminal 的两项设置为准，不会自动写入；点一次开关或「刷新状态」后才记住选择。
- 菜单只有当前状态、一个开启或关闭按钮、刷新状态和退出助手；V2 只在「退出助手」上方多了一条分隔线和一个「高级选项 ▸」子菜单。
- 保持解锁不绕过手动锁屏或登录认证。注意隐私、散热及电池消耗，运行时不要放进包内。

应用图标采用与菜单栏合盖态相同的单色 Mac Studio 外形。菜单栏图标仍按模式切换，不会始终显示主机。


## V2：全自动 AI 智能模式（2.1.7）

主菜单四项（状态 / 开启·关闭合盖运行 / 刷新状态 / 退出助手）和 1.4.1 的开关、刷新、自动纠偏逻辑保持不变，新增内容都在「高级选项 ▸」里。两个菜单的宽度在启动时固定，不随状态文字变化。

- **AI 智能模式（默认关闭）**：勾选后全自动，不需要再点「开启合盖运行」。有 Agent 任务在跑（执行中、工具运行、等待确认最长 30 分钟、暂时失联最多再算 10 分钟）就自动阻止睡眠，菜单栏变成带灯的 Mac Studio，第一行显示「AI 合盖运行中」。全部结束后等 3 分钟恢复睡眠，期间有新任务就取消；恢复时如果盖子合着、且 1 分钟内没人操作，就直接让电脑睡眠（`pmset sleepnow`）。
- **能识别的 Agent**：

  | Agent | 方式 |
  |---|---|
  | Codex（ChatGPT 桌面版、Codex App、CLI，包括本机运行的 Work） | 只读 Codex 自己的状态库 `~/.codex/sqlite/codex.db` 里“正在进行的轮次”，文件变化时才读；另有官方 Hook（系统级 `/etc/codex/hooks.json`，Codex 按策略信任，不用逐条确认） |
  | Gemini CLI | 官方 Hook（`~/.gemini/settings.json`） |
  | Antigravity | 官方 Hook（`~/.gemini/config/hooks.json`） |
  | Kiro（CLI / IDE） | 官方 Hook（`~/.kiro/hooks/clamshell-assistant.json`，只注册不会阻塞 Kiro 的被动事件） |
  | Grok Build | 官方 Hook（`~/.grok/hooks/`，装了才连接） |
  | AWS Quick 桌面版 | 只认桌面日志 `~/Library/Logs/quickwork/` 里的几个固定标签（本机工具调用、调用本机编程助手、一轮开始 / 结束），不读内容 |

  Hook 通过本机 Unix Domain Socket 上报（目录 0700、socket 0600，同用户校验，只接受应用内置的 helper）。不记录提示词、回复、工具参数或路径；会话 ID 只保存哈希值。
- **Hook 不需要你管**：AI 智能模式开着时，助手自己为已安装的 Agent 追加 Hook（先备份为 `.clamshell-backup-时间戳`，不覆盖你的条目，带注释等非标准 JSON 的配置不动）。Codex 的系统级 Hook 由安装脚本写入，需要一次管理员密码。`rollback.sh` 只移除本助手的条目。
- **后台任务一览**：「高级选项」按 Agent 显示，例如「Codex：1 个进行中」「Gemini：1 个待确认」「AWS Quick：1 个进行中」；没有任务时显示「无任务」，缓冲期显示「约 HH:mm 睡眠」。
- **手动关闭优先**：AI 正在阻止睡眠时点「关闭合盖运行」，立即恢复睡眠，这一批任务结束前不会再自动开启。「开启合盖运行」仍是手动常开开关。
- **电池与散热只显示，不干预**：「高级选项」第一行显示电量和系统散热压力等级（不是摄氏温度），打开菜单时读一次，不参与任何决定。过热或电量耗尽由 macOS 自身的硬件保护处理。
- **异常退出恢复**：开启前先写「保活租约」（进程号 + 启动时间 + 开机会话）。运行期间有一个只阻塞在管道上的守护进程 `clamshell-helper guard`，助手崩溃时它用已有的免密规则（`sudo -n`，不弹密码）把本助手设置的 `disablesleep` 恢复为 0；它也没能执行时，下次启动接管处理。不是本助手设置的禁睡眠一律不改。
- **其他**：定时停止（关闭 / 1 / 2 / 4 / 8 小时）、开机启动（SMAppService）、移除免密授权…（只在规则文件仍是本助手写入的原样时才删除）。
- **菜单栏图标**：MacBook ↔ Mac Studio 矢量动画（27×18 画布、35pt 占位、22 帧约 0.92 秒），只在状态切换时播放。
- **资源占用**：全部事件驱动。Agent 事件来自 socket 和文件变化通知，都只在智能模式开启时存在；整个程序只有一个一次性定时器，只在确实有截止时间（缓冲期、会话租约、定时停止）时才存在，并带容差。会话表最多 32 条；日志上限 64 KB，只记录本助手自己的动作。Reminal 精简服务的 Go 源码没有改动。

### 不能保证的部分
- Gemini 桌面 App 和 Grok Bot 没有本机接口，不识别。Grok Bot 的任务在云端电脑上运行，不受 Mac 睡眠影响。
- 纯远程运行的 Codex Work 不识别（它在云端执行，不受 Mac 睡眠影响）。
- AWS Quick 的识别依赖它的桌面日志格式，App 更新后可能失效；它只在云端思考、没有操作你的电脑时不计为任务。
- Antigravity 没有“等待确认”和“中断”事件，Gemini CLI 没有“中断”事件；这类情况靠租约到期处理（先显示“未知”，再到期）。
- 同一用户下的其他程序可以伪造调用内置 helper，但影响有上限：只能在会话上限内延长保持唤醒的时间，不能覆盖你的明确关闭。
- 断电、内核崩溃、注销时守护进程也会结束，这时只能靠“下次启动恢复”。

一键安装 / 升级：双击 `安装合盖助手.command`（构建 → 全部测试，失败就不安装 → 备份 → 替换 → 自动启动）。查看状态：双击 `检查智能模式.command`。回滚：`zsh rollback.sh`。更新记录见 [CHANGELOG.md](CHANGELOG.md)，设计说明见 `docs/DESIGN-V2.md`。

## 安装

1. 从 [Releases](https://github.com/mehejun876-del/clamshell-assistant/releases) 下载最新 zip，解压后把「合盖助手.app」拖进「应用程序」。
2. 本应用未经过 Apple 公证。第一次打开时，请按住 Control 键单击应用选择「打开」；也可以在「系统设置 › 隐私与安全性」里点「仍要打开」。
3. 如需开机自动启动，在「高级选项」里勾选「开机启动」（第一次可能需要在「系统设置 › 通用 › 登录项」里允许）。
4. 仅支持 Apple 芯片的 Mac，需要 macOS 14 或更高版本。

首次切换合盖模式时会请求管理员密码，写入一条只允许 `pmset -a disablesleep 0/1` 的 sudoers 规则。

## 精简版 Reminal 保留/去掉了什么

- 保留（逻辑原样复制）：合盖 / 保持解锁设置（同一个 `~/.reminal/settings.json`）、防睡眠、内屏调暗、虚拟显示器及其协调逻辑。
- 去掉：远程终端与会话、中继联网、远程窗口/桌面查看与控制、文件传输、端口转发、账号/设备配对、自动升级、MCP/Agent 集成；也不再需要远程合盖会话。
- 如果本机另外装了完整版 Reminal，它们共用设置文件；虚拟显示器/调暗由已运行的 Reminal 守护进程优先负责，精简版自动让位。

## 从源码构建

需要 Xcode 命令行工具。装了 Go 1.26 时从 `ThirdParty/reminal-lid` 源码构建 Reminal 精简版；没有 Go 时自动使用 `prebuilt/` 里取自 1.4.1 官方安装包、经 SHA-256 校验的同源二进制（也可用 `REMINAL_LID_BIN` 指定）。

```sh
./build.sh
```

只构建 `build/合盖助手.app`，不修改 LaunchAgent、电源设置或 Reminal 偏好。

非侵入回归测试（写操作全部替身模拟）：

```sh
zsh test.sh      # 类型检查 + 自检（1.4.1 回归 + V2 场景）+ go vet + helper 冒烟测试
```
